# Phase 2 Day 2: The Anatomy of the Internet (Web Basics)

You have mastered Python Core. You know how to write logic on your own computer. But right now, your code is trapped inside your laptop. 

To become an AI Engineer, your code needs to be able to talk to other computers across the world. You need to build **Web Servers**. 

Before we write code for a server, you must understand the language that computers use to talk to each other. That language is called **HTTP**.

### The Learning Checklist (Search these on YouTube)
Do not write any code tonight. Your only job is to watch videos on these 5 concepts until you understand them deeply.

1. **Client-Server Architecture:** 
   - What is a Client? (Your browser/phone)
   - What is a Server? (A computer sitting in a data center waiting for orders)
   - *Search on YouTube: "Client Server Architecture explained simply"*

2. **HTTP Methods (The Verbs of the Internet):**
   - What is a `GET` request? (Asking for data)
   - What is a `POST` request? (Sending new data)
   - What is `PUT` and `DELETE`?
   - *Search on YouTube: "HTTP GET vs POST explained"*

3. **HTTP Status Codes (The Server's Reply):**
   - What does `200 OK` mean?
   - What does `404 Not Found` mean?
   - What does `500 Internal Server Error` mean?
   - *Search on YouTube: "HTTP Status Codes in 100 seconds"*

4. **JSON (JavaScript Object Notation):**
   - This is the universal format for sending data across the internet. It looks exactly like a Python Dictionary.
   - *Search on YouTube: "What is JSON? JSON vs Python Dictionary"*

5. **What is an API? (Application Programming Interface):**
   - How do two different softwares talk to each other?
   - *Search on YouTube: "What is an API? APIs explained simply"*
