# The 10-Minute Flashback
*Testing the Foundation.*

**Time Limit: 10 Minutes.**
No looking at old notes. Prove to your brain that you still know the basics. 

---

### Question 1: The Filter
Write a function `get_evens(numbers_list)`. 
Pass it a list of random numbers. 
Inside the function, use a `for` loop to check if a number is even (hint: modulo `% 2 == 0`). If it is even, append it to a new list. 
**Return** the new list of even numbers and print it.

### Question 2: The Dictionary Loop
Create a dictionary of 3 students and their grades. 
Example: `grades = {"Aryan": 95, "Elon": 88, "Steve": 70}`. 
Use a `for` loop and `.items()` to loop through the dictionary. 
For every student, print exactly: `Student [Name] scored [Grade]`.
